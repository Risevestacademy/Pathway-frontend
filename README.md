# Pathway

Pathway helps people pick a tech career and follow a clear, step-by-step roadmap to get there. Users explore careers, see the roadmap and resources for each one, check where their skills stand, and (when signed in) save a pathway.

This is the frontend. The backend lives in a separate repo and is deployed on Render.

## Tech stack

- Vite, React 19, TypeScript
- Tailwind CSS v4
- TanStack Router (file-based routes)
- TanStack Query v5 for server data
- Zustand for client state (auth, session, UI, admin)
- Axios (one shared instance with token refresh)
- Zod for validation
- Sentry for error tracking
- PostHog for analytics (loaded lazily in its own chunk)
- Vitest, Testing Library and MSW for tests
- Deployed on Vercel

## Getting started

You need a recent version of Node (LTS).

```bash
npm install
cp .env.example .env
npm run dev
```

Open the local URL that Vite prints.

### Environment variables

Copy `.env.example` to `.env` and fill in the values.

| Variable | What it is for |
| --- | --- |
| `VITE_API_BASE_URL` | Base URL for API calls. |
| `VITE_GOOGLE_CLIENT_ID` | Google sign-in |
| `VITE_POSTHOG_PROJECT_TOKEN` | PostHog analytics |
| `VITE_POSTHOG_HOST` | PostHog host |
| `VITE_SENTRY_DSN` | Sentry error tracking |
| `VITE_SENTRY_ENVIRONMENT` | Sentry environment name |
| `VITE_SENTRY_ENABLE_DEV` | Set to `true` to send Sentry events from dev |
| `VITE_ADMIN_OWNER_EMAIL` | Admin owner email |
| `VITE_ADMIN_OWNER_NAME` | Admin owner name |

In development, Vite proxies `/api` to the deployed backend (see `vite.config.ts`). In production, `vercel.json` rewrites `/api` to the backend.

## Project structure

The code is organized by feature.

```
src/
  features/      One folder per feature (components, hooks, utils, types, tests)
    admin/       Admin screens (careers, reviews, reports, team)
    auth/        Login, signup, verify email, reset password
    careerDetail/  Career header, details, roadmap, resources
    catalog/     Career catalog data and helpers
    explore/     Explore careers
    feedback/    Feedback form
    landing/     Landing page
    pathway/     Roadmap and pathway steps
    progress/    Progress (not built yet)
    resources/   Learning resources
    skillCheck/  Skill check hub, questionnaire, result, roadmap
  components/    Shared UI (Button, Card, Dialog, Modal, Select, Skeleton, StateMessage, and more)
  lib/
    api/         API calls, one file per area, plus the shared Axios instance
    monitoring/  Sentry and analytics events
    stores/      Zustand stores
    queryKeys.ts Central list of TanStack Query keys
  routes/        File-based routes
  test/fixtures/ Test data (mock data used in tests only)
```

### Routes

- Public: landing (`/`), explore, career pages (details, roadmap, step pages, resources), onboarding
- Auth: login, signup, verify email, reset password
- Protected (needs sign-in): admin, progress, skill check

## Testing and CI

Tests run with Vitest in a jsdom environment. Test data lives in `src/test/fixtures`. Do not import fixtures in production code.

GitHub Actions (`.github/workflows/ci.yml`) runs on every pull request:

1. `npm ci`
2. `npx tsc --noEmit`
3. `npm run lint`
4. `npm test`
5. `npm run build`

Run these locally before opening a PR.

## Working on the project

- Never push to `main`.
- Branch off `dev`, named by type, for example `feat/...`, `fix/...`, `chore/...`.
- Open a pull request into `dev`.
- Get at least one review before merging.
- Pull `dev` into your branch before you push, and run `npm install` after pulling in case dependencies changed.

### Code conventions

- Every screen handles loading, empty, error and success states.
- No hard-coded mock data in production code. Put it in `src/test/fixtures`.
- Add new query keys in `src/lib/queryKeys.ts`.
- Keep forms labelled and keyboard accessible, and respect `prefers-reduced-motion`.

## Deployment

The app is deployed on Vercel. `vercel.json` rewrites `/api` requests to the backend at `https://pathway-backend-a89a738.onrender.com` and falls back to `index.html` for client routes.
